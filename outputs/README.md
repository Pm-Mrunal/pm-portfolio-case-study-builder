# Outputs

Generated case studies are saved here automatically.

File naming pattern: `[project-slug]-v[N]-[YYYY-MM-DD].md`

Example: `onboarding-redesign-v1-2024-11-15.md`

Each file contains:
- Recruiter TLDR (350-500 words)
- Detailed hiring manager version (1,800-2,800 words)
- Portfolio headlines and subtitles
- Visual plan JSON (4-8 suggested visuals with placement and rationale)
- Visual captions JSON (production-ready caption text for each visual)

---

This folder is excluded from git by default (see `.gitignore`).
Your case studies are private — they won't be committed to any repository unless you explicitly add them.
