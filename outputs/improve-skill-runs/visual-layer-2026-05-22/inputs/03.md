# Input 03 — Adjacent Natural Language (Routing Surface Test)

**Type:** Adjacent NL — does not use a verbatim trigger phrase; tests latent routing surface

**User message:**
```
I just finished generating my case study for the outflow-ai project. I want to make it more visual so it stands out in my portfolio — can you help me figure out what charts or diagrams I should add, and where they should go?
```

**What this tests:**
Whether the description provides enough latent routing surface to fire on natural-language phrasings that don't include explicit skill commands. A user finishing the /generate pipeline and wanting to add visuals would use language like this. If the skill description has no trigger phrases and the "When to Use" section is buried in the body, this input will fail to invoke the skill and Claude will respond conversationally from training data without running the pipeline.
